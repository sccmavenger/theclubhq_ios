## Making new posts
Start from `templates/blank-feed_1080x1350.png` or `templates/blank-story-reel-tiktok_1080x1920.png` in Canva, Express or Illustrator.
- Headlines: **Outfit ExtraBold**, white, with one key phrase in cyan `#00C2FF` or orange `#FF8A00`.
- Body text: **Inter Medium**, `#B7C4D8`.
- Install both fonts from Google Fonts (free) before editing on your computer.
- One accent color per post. Use orange for calls to action and money, cyan for everything else.
