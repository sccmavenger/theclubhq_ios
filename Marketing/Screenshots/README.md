# ClubHQ app screenshots

47 screenshots of the ClubHQ iPhone app for social, marketing, and press posts. Pick whatever you need.

- **Device:** iPhone 18 Pro Max simulator, iOS 27, 1320 × 2868 px PNG, clean 9:41 status bar.
- **Data:** the built-in demo team (Mayhem Elite 14U). No real families' names or info appear.
- **Captured:** October 24, 2026. These show the current alpha app icon, which is being redesigned.
- Files are numbered in the order someone would see them, so each folder reads like a walkthrough.

## Notes

- `01-home-screen-app-icon.png` also shows other apps on the simulator's home screen (including The Hub). Crop it, or use something else, if you don't want them in a post.
- These are raw screens with no device frames or captions. The polished App Store set is in `design/app-store-screenshots/`.
- To regenerate: build Debug, then launch with `-ScreenshotPersona coach|parent|player`, `-ScreenshotTab home|schedule|team|messages|more`, and `-ScreenshotOpen chat|event|tour` (see `docs/APP_STORE.md`).
